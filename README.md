# AI Prompts Hub

A modern, responsive AI prompts and editorial platform built with Next.js, TypeScript and Tailwind CSS.

## Features
- Prompt library with search, categories and copy-to-clipboard
- Editorial blog, tutorials and AI resources
- Responsive homepage and content layouts
- SEO metadata, sitemap and robots.txt
- Admin-ready architecture (connect a database and authentication before enabling publishing)

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deployment
Import this repository into Vercel. Set the framework preset to Next.js and deploy. Configure `NEXT_PUBLIC_SITE_URL` to your production URL.

## Monetization
AdSense, affiliate links and digital products require the publisher's own accounts, verified disclosures, privacy/consent pages and approval. No advertising or affiliate account is preconfigured.
